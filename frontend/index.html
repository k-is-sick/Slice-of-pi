How it works

The Phyllotaxis Spiral

Each of the 100 million digits in π is laid out in a phyllotaxis spiral — the same pattern found in sunflower seeds. Digit i sits at radius r = c·√i and angle θ = i · 137.508° (the golden angle). This places every digit at a unique, computable position in O(1) time.

Search index

Short queries (≤ 7 digits) are answered in O(1) using pre-built direct-address tables. Longer queries use binary search on a suffix array over all 100 million digits — a sorted index of every possible starting position. The SA occupies ~400 MB on disk and is never fully loaded into RAM (memory-mapped).

Why long numbers may not be found

A random k-digit string appears in N digits of π about once every 10k digits. With 100M digits indexed, a 9-digit string has a ~63% chance of appearing, a 12-digit string has ~0.01%. Numbers not found are shown with their longest matching prefix and the expected position in a longer π expansion.

Position convention

Position 1 is the first digit after the decimal point (the "1" in 3.14159…). The integer part "3" is not stored.

Memory sizing

  • Digit file: N bytes (1 byte/digit)
  • Suffix array: ~4N bytes (uint32 for N < 4B)
  • Tier-1 tables k=1..7: ~43 MB total
