## 1. Project Overview & Position Convention

- **Core Goal:** Interactive, sub-millisecond search and 60 FPS 3D spatial visualization of the decimal expansion of $\pi$ across billions of digits.
- **Position Convention:**
  - **Position 1** corresponds to the first digit following the decimal point:
    $$\pi = 3.\mathbf{1}4159265\dots \implies \text{pos } 1 = 1, \text{pos } 2 = 4, \dots$$
  - The leading integer digit (`3`) is not stored or indexed in search tables.

## 3. Mathematical Foundations & Invariants

### 3.1 Fibonacci Sphere Surface Confinement ($S^2$)
All $N = 1,000,000$ points are mapped to the 2-sphere of radius $R = 100$ via Fibonacci distribution in [`frontend-3d/src/math.js`](file:///d:/Slice_of_pi/frontend-3d/src/math.js):
- **Polar angle:** $\cos\theta_i = 1 - \frac{2(i + 0.5)}{N}$, $\sin\theta_i = \sqrt{\max(0, 1 - \cos^2\theta_i)}$
- **Azimuthal angle:** $\phi_i = (i \cdot \phi_{\text{golden}}) \pmod{2\pi}$ where $\phi_{\text{golden}} = \pi(3 - \sqrt{5}) \approx 2.39996323\text{ rad}$
- **Cartesian:** $x = R \sin\theta \cos\phi$, $y = R \cos\theta$, $z = R \sin\theta \sin\phi$
- **Invariant:** $\|\vec{p}\|_2 \equiv 100.000$ for all indices. Clamped edge cases fall back to North Pole $(0, R, 0)$.

### 3.2 Geodesic Spherical Linear Interpolation (SLERP)
- To prevent straight lines from cutting through the sphere interior, connections between waypoints are calculated via SLERP on $S^2$:
  $$\vec{p}(t) = (R + 0.35) \left( \frac{\sin((1-t)\Omega)}{\sin\Omega} \hat{u} + \frac{\sin(t\Omega)}{\sin\Omega} \hat{v} \right)$$
- The $+0.35$ radial offset prevents depth-buffer $z$-fighting with the sphere surface.

### 3.3 Data-Driven Heading Steering
- Avoid fixed-index step increments which produce symmetric star polygons ($\{8/3\}$ or $\{13/5\}$ polygrams).
- Consecutive digits $d_k, d_{k-1}$ steer heading turns and arc step distances in local tangent space $(\hat{u}, \hat{v})$:
  $$\Delta\alpha_k = (d_k - 4.5) \cdot 0.72 + (d_{k-1} \cdot 0.31 - 1.4)$$
  $$\Delta\sigma_k = 0.14 + \Big( (7 d_k + 3 d_{k-1}) \bmod 10 \Big) \cdot 0.016 \text{ rad}$$
- Startup verification `assertSphereMapping()` tests 1,007 points + 6 query trajectories.

## 4. Backend Engine Details

- **Runtime:** Python 3.12 (executable located at `$env:LOCALAPPDATA\Programs\Python\Python312\python.exe`).
- **Initialisation:** `backend.search.initialise()` loads memory-mapped NumPy tables on FastAPI lifespan startup.
- **Tier 1 ($k \le 7$):** Direct address integer array lookup ($O(1)$) in $\approx 0.008\text{ ms}$.
- **Tier 2 ($k > 7$):** Binary search over Suffix Array via `pydivsufsort` ($O(k \log N)$) in $\approx 0.082\text{ ms}$.
- **Fallback Import:** `server.py` handles both root execution (`from backend import search`) and nested execution (`import search`).

## 5. UI & Interaction Layer

1. **Type-to-Search:**
   - Any single printable keystroke (`e.key.length === 1`) captures focus into `#search-input` without requiring a prior click.
   - If the hero was hidden after an arrival, typing automatically restores the hero search box and clears previous query text.
   - `ExploreController.js` ignores keydown events when an input element is active, preventing WASD camera movement while typing.
2. **Explore Button:**
   - Label is simply `Explore` with no emojis.
3. **Visual Aesthetics:**
   - Cosmic navy background (`0x050712`).
   - Ambient light `0x6070a0, 0.7` + directional light `0xfff0dd, 1.2` at $(200, 300, 200)$.
   - Procedural celestial objects: ringed Saturn gas giant, heliocentric solar system with corona sun, 4 spiral galaxies, shooting stars.
